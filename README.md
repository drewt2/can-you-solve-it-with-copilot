# Can You Solve It With Copilot?

A public Microsoft Copilot assessment that helps users practice selecting the best Copilot experience and crafting effective prompts to solve real business problems.

## Features

- Beginner, Intermediate, and Advanced scenarios
- Random scenario mode
- Tool selection scoring
- Prompt quality scoring
- Prompt maturity levels
- Guided feedback
- Recommended solutions
- Newsletter sign-up opportunities
